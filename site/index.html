05 / KNOW WHAT THE DATA CAN SAY

Source-backed. Reproducible.

Original records preserved

Data integrity

Blank and whitespace-only measurements stay missing. Yields above 100% remain unchanged and are available in the review filter. Both files join one-to-one on batch ID; product codes are cross-checked.

Public identifiers describe anonymized records, not identifiable suppliers. The dashboard uses published batch-level process features, not the full 10-second sensor trajectories.

Sources & scope

Janja Žagar and Jurij Mihelič, Big data collection in pharmaceutical manufacturing and its use for product quality predictions, Scientific Data (2022).

Raw CSVs are unchanged. This project joins records, standardizes month labels, and derives weighted yields, review flags, target-equivalent gaps, and descriptive associations.

No stock-on-hand, expiry, supplier lead-time, price, or savings records are supplied. This project supports manufacturing-performance review and does not certify batch release or represent Boston-specific operations.
